Tentang Layanan

Server ini menyediakan ruang hosting bagi mahasiswa untuk menjalankan basis data dan prototipe antarmuka pada kegiatan praktikum. Layanan dibangun dari komputer lama yang dialihfungsikan menjadi home server hemat energi dengan perangkat lunak sumber terbuka.

Halaman ini sengaja berisi teks, tabel, dan gaya sederhana tanpa gambar, sehingga ukuran dan isinya sama persis di setiap perangkat yang diuji. Dengan demikian, perbedaan hasil uji hanya berasal dari perangkat, bukan dari konten.

Ketentuan Penggunaan

  1. Setiap kelompok memakai satu basis data sesuai nama kelompok.
  2. Kata sandi akun tidak dibagikan kepada pihak lain.
  3. Data pribadi tidak disimpan di server praktikum; gunakan data contoh.
  4. Aplikasi yang membebani server secara berlebihan dapat dihentikan oleh pengelola.
  5. Cadangan data dibuat secara berkala oleh pengelola laboratorium.
